[Découvrir ContextPacker](https://contextpacker.vercel.app/)

Elle propose aussi des préréglages par rôle et un accès rapide à vos sites de statistiques préférés. [Découvrir OTP LOL](https://qurnt1.github.io/otp_lol/)
